# Site Diary

Gujarati-first construction site management for small and mid-size builders: labour attendance, material in/out and stock, daily progress with photos, approvals, wages, and a nightly owner report.

- `apps/mobile` — Expo app for supervisors, store keepers and engineers (works offline; also runs in a browser)
- `apps/web` — Next.js office panel for owners and accountants
- `apps/api` — Express + Prisma + PostgreSQL, pg-boss jobs

Try it: `docs/testing.md`. Deploy: `docs/deployment.md`. Product scope: `docs/scope.md`. For contributors and Claude Code: `CLAUDE.md`.
